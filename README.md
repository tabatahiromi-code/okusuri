# おくすり手帳

ブルー系の本人専用お薬手帳。Sitesの本人限定公開向けのアプリです。

## 機能

- スマートフォンの背面カメラによる撮影（HTTPSが必要）
- 端末カメラと画像ファイルの選択にも対応
- 読み取り前にシール部分を切り抜き・90度回転。画像の明るさ調整と小さな傾きの補正に対応
- Tesseract.js 7と日本語向けの高精度文字種モデルによるOCR。エンジンとモデルを同梱し、画像を外部の認識サービスに送信しない
- 処方日、医療機関、薬局、薬名、用法・用量の入力候補を作成
- 原画像とOCR原文を確認して修正。原本の確認にチェックしてから保存
- 記録の一覧・検索・並べ替え・編集・削除・JSONバックアップ
- D1に記録を保存し、Sitesの認証ユーザーIDで読み書きを制限

読み取りは自動判定のため誤字や項目の抜けがあります。撮影した画像は保存せず、確認した文章・記録だけを保存します。記録には医療情報が含まれます。Sites側の本人限定アクセス制御も必ず有効にしてください。

## Sitesへの公開

`.openai/hosting.json` のSite IDとD1の `DB` バインディングを使います。`npm run db:generate` でDrizzleマイグレーションを生成し、`npm run build` でWorker・静的アセット・マイグレーションを `dist/` にまとめます。Sitesの本人限定公開を使用してください。

独自のログインは実装していません。APIはSitesが付与する `oai-authenticated-user-id` を信頼するため、Sitesの認証とアクセス制御を通して配信してください。画像はブラウザ内で読み取り、確認後の記録だけを保存します。

## 確認

`npm run check` と `npm test`。認証、所有者によるデータの絞り込み、別オリジンの書き込み拒否、入力検証、読み取り候補を確認。3種類の薬名・用量を含む架空シール（鮮明・小サイズ・傾き）の画像を使ったOCR回帰テストも実施。スマホ画面サイズのChromiumで画像選択・切り抜き・回転・OCRを確認済み。実機カメラと公開環境での保存は未検証。
