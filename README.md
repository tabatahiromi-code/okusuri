# おくすり手帳

ブルー系の本人専用お薬手帳。**このリポジトリのコードは作成済みですが、Sitesへの登録・データベース接続・本人限定公開は未完了です。実運用の記録を入れる前に公開設定を完了してください。**

## 機能

- スマートフォンの背面カメラによる撮影（HTTPSが必要）
- 端末カメラと画像ファイルの選択にも対応
- Tesseract.js 7の日本語・英語OCR。エンジンとモデルを同梱し、画像を外部の認識サービスに送信しない
- 処方日、医療機関、薬局、薬名、用法・用量の入力候補を作成
- 原画像とOCR原文を確認して修正。原本の確認にチェックしてから保存
- 記録の一覧・検索・並べ替え・編集・削除・JSONバックアップ
- D1に記録を保存し、Sitesの認証ユーザーIDで読み書きを制限

読み取りは自動判定のため誤字や項目の抜けがあります。撮影した画像は保存せず、確認した文章・記録だけを保存します。記録には医療情報が含まれます。Sites側の本人限定アクセス制御も必ず有効にしてください。

## 公開作業の残り

このセッションでSitesスキルと公式制作・公開ヘルパーが利用できなくなったため、Siteの作成と公開は行っていません。Sitesの接続・スキルが利用可能な環境で、公式ワークフローを再開してください。

1. Sitesの公式Worker対応スターターにこのコードを移し、`public/` をアセット、`src/worker.js` をWorkerエントリに設定する。
2. Sitesで新規Siteを作成し、返されたIDを `.openai/hosting.json` に保存する。本人限定のままにする。
3. 論理D1バインディング `DB` とスキーマを宣言し、`migrations/0001_records.sql` を公式スターターのマイグレーション形式へ組み込む。`wrangler.jsonc` のIDは未設定の目印で、本物のDBではない。
4. 公式ヘルパーでソース同期・検証・ビルド・パッケージ作成を行い、本人限定デプロイを実行する。
5. スマートフォン実機でカメラ許可、OCR、保存、再表示を確認する。他のユーザーがサイトへアクセスできないことも確認する。

独自のログインは実装していません。APIはSitesが付与する `oai-authenticated-user-id` を信頼するため、このヘッダーを外部から偽装できる一般公開のWorkerとしてそのまま配信しないでください。

## 確認

`npm run check` と `npm test`。認証、所有者によるデータの絞り込み、別オリジンの書き込み拒否、入力検証、読み取り候補を確認。日本語の生成シール画像を使ったOCRの動作確認も実施。実機カメラと公開環境での保存は未検証。
