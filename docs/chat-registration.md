# このチャットから直接登録する

JSON取り込みを残したまま、Siteが公開する本人認証付きの連携を追加しています。画像の読み取りはこのチャットが行い、外部のAI APIはアプリから呼びません。

## 初回の接続

Siteの公開時に作成される「おくすり手帳」連携をインストール・接続してください。チャットに連携が表示されない場合は、新しいチャットで接続した「おくすり手帳」を選びます。接続確認には読み取り専用の `get_notebook_status` を使います。

## 登録手順

1. ユーザーが送ったシール写真から、見えている記載だけを抽出します。写真外・判読できない箇所を一般的な処方や薬の知識から補ってはいけません。未確認の用量は空欄、確認事項はメモに残します。処方日ごとに記録を分けます。
2. `preview_medicine_records` に記録を渡し、返された内容と未確認項目をユーザーへ提示します。この段階では保存しません。
3. ユーザーが内容を明示的に了承した後に `save_medicine_records` を呼びます。同じ記録と `preview_token`、`confirmed: true` が必要です。記録を変更した場合は再プレビューします。
4. ツールが返した `imported` / `skipped` 件数を伝えます。成功を確認するまで保存済みと伝えてはいけません。

## 実装と保護

- `.openai/hosting.json` の `capabilities: ["mcp"]` と `POST /mcp`。
- SitesがMCPの本人認証とSiteの閲覧権限を検証します。データ操作には渡されたSite内ユーザーIDを必須にし、引数で所有者を指定することはできません。
- 接続情報とツール一覧の取得だけは利用者IDやデータベースを必要としません。薬の記録は返しません。
- プレビューのトークンは利用者IDと正規化した記録に結び付けています。別の利用者や異なる内容には使えません。これは認証情報の代わりではなく、認証された本人が確認した内容との対応をチェックするためのものです。
- 保存はJSON取り込みと同じトランザクション・重複防止処理を共有します。追加のみで、既存の記録を上書き・削除するツールは公開しません。
- APIキー、共通のサービス用認証情報、公開の登録エンドポイントは追加していません。
- 実際の患者写真や抽出した記録を、コードやテストに含めないでください。
