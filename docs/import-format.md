# チャットで抽出したJSONの取り込み

写真をこのチャットに渡し、「このアプリの取り込み用JSONを作ってください。推測で補わず、不明な用量は空欄、確認事項はメモに残してください」と依頼します。ダウンロードしたJSONをアプリの「JSON取り込み」で選び、内容を確認して保存します。AI APIの契約・設定は不要です。

一度に1〜100件、ファイルは2MB以下。バックアップと同じ `version: 1` / `records` 形式です。実際の患者情報はソースコードやテストに含めないでください。

```json
{
  "version": 1,
  "records": [{
    "date": "2026-10-18",
    "clinic": "",
    "pharmacy": "",
    "medicines": [{"name": "テスト薬", "dosage": ""}],
    "note": "用量は未確認。原本と照合してください。",
    "originalText": ""
  }]
}
```

`date` は処方日（西暦の年月日）。`clinic`、`pharmacy`、`note`、`originalText` は未記入でも空文字列を指定します。各記録に少なくとも1件の薬名が必要です。複数の処方日がある場合は記録を分けます。

取り込みは追加のみです。ファイル内のIDや所有者情報は使用せず、現在ログインしている本人に新しいIDで保存します。同じ日付でも内容が違う記録は別に追加します。内容がすべて同一ならスキップします。ファイル全体を検証してからトランザクションで保存するため、一部だけの取り込みは行いません。保存済みの誤読記録は一覧から確認して編集・削除してください。
